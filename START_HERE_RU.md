# Быстрый запуск JANA ADDRESS · Команда 67

## Офлайн (как на приёмке)

```bash
docker load -i jana-address-team67-mvp.tar   # один раз; интернет не нужен
docker compose up -d                          # ничего не собирает и не скачивает
```

Открыть **http://127.0.0.1:8000/**, нажать **«Загрузить демо»**. Проверка: `curl -sS http://127.0.0.1:8000/health` → `"ready":true`.

Если порт занят: `JANA_PORT=8010 docker compose up -d`. Остановка: `docker compose down`.

## Сборка из исходников (нужен интернет один раз)

```bash
docker compose up -d --build
```

Офлайн-сборки нет: `pip install` требует PyPI (проверено: `docker build --network none` падает). Поэтому для среды без сети — только готовый образ выше.

## REST

```bash
curl -X POST http://127.0.0.1:8000/api/v1/addresses/parse-batch \
  -H 'Content-Type: application/json' \
  --data-binary @data/demo_input.json
```

Документация-страница `/docs` **отключена** (тянула скрипты с CDN). Схема — `GET /openapi.json`.

Одна плохая запись больше не отклоняет весь batch: она возвращается пустым объектом с `confidence 0.0`, а число таких записей — в заголовке `X-Jana-Invalid-Items`. Это **временное командное решение** (контракт v1.1), организаторами не подтверждено.

## Что с train.json?

Организаторы его не выдали; он не нужен — парсер не обучается. Для замеров есть `data/synthetic_corpus_v1.json` — 1200 **синтетических** строк без меток. Это не датасет организаторов и не доказательство точности.

## Точность

Скрытый набор не измерен. На собственной закрытой выборке (72 записи, ручная разметка) — 66/72 полных совпадений; это оптимистичная оценка на синтетике, а не точность на реальных адресах. Подробно и с оговорками: `docs/ACCURACY.md`.

## Ограничения

- Справочник — административные имена (91 город, 22 района в 5 городах, 14 микрорайонов Алматы), **без улиц и домов**; это не полный КАТО/ОСМ.
- Название магазина даёт только `landmark`; адрес из POI-записей не подставляется никогда.
- Слитные строки без пробелов (`Жандосова45кв12`) не разделяются — известное ограничение.
- Публичный сервер работает без аутентификации: не загружайте туда чужие персональные данные.

Полная информация — в `README.md`.
