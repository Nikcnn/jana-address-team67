# Точность: что измерено, а что нет

> **Скрытый набор жюри не измерен.** Здесь только прокси-метрики на собственных синтетических выборках. Ни одно число ниже не является официальной точностью и не должно так подаваться.

## Главное

| Выборка | n | Record EM (все 11 полей) | Взвеш. прокси-точность | Статус выборки |
|---|---|---|---|---|
| holdout v1 | 107 | 105/107 | 0.999 | **Загрязнена**: использовалась для подбора правил → цифра показывает переобучение, а не качество |
| holdout v3 (закрытая) | 72 | 66/72 (91.7%) | 0.976 | Ручная разметка **до** прогона парсера, один прогон, в тюнинге не участвовала |

Разрыв между v1 и v3 — прямое доказательство, что высокие числа на «своей» выборке ничего не значат. Обе выборки написаны синтетически в стиле примеров ТЗ; разметчик — тот же оркестратор, что ставил задачи на правила. Поэтому **v3 — оптимистичная оценка сверху**, а не ожидание на реальных адресах.

Как читать:
- `Верно (норм.)` — сравнение после нормализации S1 (нижний регистр, пунктуация/символы → пробел, схлопывание пробелов). Пустое значение против пустого gold тоже считается верным, поэтому колонка завышена на разреженных полях.
- `Recall на непустом gold` — только записи, где в разметке значение есть. Это честнее для полей, которые часто остаются `null`.
- `Ложно заполнено (false-fill)` — предсказано значение там, где gold `null`. Для нашей задачи важнее всего: выдуманный город/улица хуже, чем `null`.
- Все нарушения контракта (14 полей, типы, `raw_address`) — **0 записей**.

## Категории ошибок (v3, 6 записей из 72 не совпали полностью)

| Категория | Что произошло | Решение |
|---|---|---|
| Слитные строки без пробелов (`Жандосова45кв12`, `Мира8кв1`, `ул.Ауэзова15/2кв9`) | название улицы/дом/квартира не разделены → поля `null`, в одном случае дом обрезан до `15` вместо `15/2` | известное ограничение; в ТЗ такие примеры даны с пробелом (`Назарбаева8 кв5`) и разбираются верно |
| `17микрорайон 5дом 33кв` | слитный маркер микрорайона не распознан | то же ограничение |
| `Туран 28/3 3подьезд` | опечатка `подьезд` (без `ъ`) учтена, но слитная форма с числом — нет | частично |

Все остальные расхождения v3 — в этих же трёх записях (по нескольким полям сразу). Ложно заполненных значений в v3 **нет** (`false-fill` = 0 по всем полям, кроме диагностического разбора слитных строк).

## Что это значит для защиты

1. Официальная точность — **NOT MEASURED**, пока жюри не прогонит свой набор.
2. Наш кандидат не выдумывает географию: `false-fill` = 0/22 (province, city), 0/65 (district), 0/5 (street_name/house на непустом gold).
3. Числа v1 (99.9%) приводить как достижение нельзя — это переобучение на своей выборке; в отчёте они даны только для контраста.

## Как воспроизвести

```bash
python scripts/eval_holdout.py --holdout <holdout.json> --url http://127.0.0.1:8000/api/v1/addresses/parse-batch --json-out eval.json
```

Выборка v3 хранится вне репозитория и образа (один прогон, sha256 `5eaee5c9938bdcbf719086bae3a10c6e03bd3e461819f3ce6ee6e1377cbb0416`). Метрика — `scripts/eval_holdout.py`, правило S1 — `lower(); characters of unicode category P*/S* -> space; collapse whitespace; strip`.
